# Vanta examples

## Browse by difficulty
- **Beginner** (`Console`/`math`): `text_bench.vnt`, examples types `loops.vnt`.
- **Intermediate** (`Physics`/`Enums`): `enum_enums_advanced.vnt`.
- **Architecture/Systems** (`Tier 1 demo`, ECS): `boids.vnt`, `strike.vnt`, `pong.vnt`.
- **Tooling** (`debug`, `text formatting`): `text_bench_headless.vnt`.

## Run one
```
vanta examples/posix_headless.vnt  # for bit of a no sdl
vanta examples/enums_advanced.vnt
```
Run `vanta check examples` quick.
Notes: SDL libs needed for many; Build Tools for night versions.
