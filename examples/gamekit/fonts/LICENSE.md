# tom-thumb.ttf — license and provenance

A very tiny (3x5 pixel) monospace bitmap font, converted to TrueType.

- Original font ("Tom Thumb", 3x5): **Brian Swetland**, with readability
  tweaks by **Robey Pointer** —
  <https://robey.lag.net/2010/01/23/tiny-monospace-font.html>
- License: **CC0 / CC-BY 3.0** (as stated by the source project)
- PNG-to-TTF conversion: **gheja**, <https://github.com/gheja/tom-thumb-ttf>
  (the `Tom Thumb Monospace.ttf` file, renamed here to `tom-thumb.ttf`)

It ships with the Vanta game kit so examples, tests, and docs do not depend
on whatever fonts a machine happens to have.
